# Runbook: read my queue

Story S6.3.2 (ADR 0058). What needs a person today — approvals, exceptions assigned, breaks to
explain, drift changes — aggregated straight from the report files this factory's own agents
already wrote, filtered by role. No credentials, no new dependency: reads JSON already on disk.

## Running it

```bash
astra-control queue show \
  --gate-pack work/gate-evidence-compiler/pershing_position-2026-09-13/gate_pack.json \
  --exception-report work/exception-triage/report.json \
  --break-report work/break-explainer/pershing/2026-09-01/report.json \
  --drift-report work/drift-watcher/pershing_gcus/2017-07-25/report.json \
  --role ops
```

Every `--*-report`/`--gate-pack` flag is repeatable and optional — pass every report you have for
today; a source with nothing to queue (or a path that doesn't exist) contributes nothing, not an
error. `--role` filters to one role's own items; omitted, shows everyone's. Exit 0 means nothing
needs the given role (or, unfiltered, nobody) today; exit 1 means the queue is non-empty.

Read the report:

1. **Approval** — a release whose gate pack has everything else met, only approval outstanding.
2. **Exception** — an Exception Triage suggestion not already auto-applying; a code with no
   taxonomy entry at all is included the same way, no separate check needed.
3. **Break** — a Break Explainer difference marked `explained: false` — its own "needs a person"
   category, nothing wider.
4. **Drift** — every Drift Watcher finding; that report has no "already handled" signal, so
   nothing here is filtered out on your behalf.

## Deciding

- **An item you expected is missing**: check the underlying tool actually ran for today and wrote
  its report to the path you gave — this tool never infers a queue item from anything but a real
  file.
- **A break you know about is not queued**: check `explained_rate` in that report directly — if
  it is 1.0, Break Explainer already explained everything; there is genuinely nothing to queue.
- **The queue looks the same for two different roles**: check `astra-control permissions show`
  and this story's own role mapping (ADR 0058 point 3) — some kinds are shared between two roles
  on purpose (approvals: steward and PM; breaks: steward and ops).

## Notes

- `control/examples/queue/` is real output, not hand-authored: each report was generated by
  running the real agent CLI (`exception-triage`, `break-explainer`, `drift-watcher`,
  `gate-evidence-compiler`) directly against that agent's own already-committed example fixtures.
- The published My Queue artifact is where "counts refresh without reload" and "items open the
  right screen in one click" are actually demonstrated — a CLI invocation is itself a reload, so
  neither claim can be shown here. No destination screen exists yet for any of the four kinds
  (S6.2.4, S6.2.5, S6.3.7, S6.3.9 are all still backlog); the artifact says so per item rather
  than linking to a screen that is not real.
